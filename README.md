# iPad Offline AI（ビルド不要版）

iPad上でAIモデルを動かす、完全オフライン対応を目指したチャットWebアプリです。
推論は `@mlc-ai/web-llm`（WebGPU）で端末内に実行され、会話内容はサーバーに送信されません。

> ⚠️ **実機未確認です。** コードの構文チェックまでは行いましたが、iPad実機での動作確認はできていません。
> 特に「モデル読み込み」「機内モードでの再起動」は、必ずご自身のiPadで確認してください。

## 構成（ビルド不要・静的ファイルのみ）
index.html / style.css / app.js / worker.js / webllm-url.js / sw.js / manifest.webmanifest / icon-*.png

## 1. iPadだけで公開する（HTTPS必須）
Service Worker（オフライン保存）は HTTPS のページでしか動きません。ZIPを開いて直接開くだけでは動きません。
静的ホスティングに置いてください（以下は一般的な手順で、こちらでは実際に試していません）。

### 方法A：GitHub Pages
1. iPadの「ファイル」アプリでZIPをタップして展開します。
2. Safariで github.com にログイン →「New repository」（Publicで作成）。
3. 「uploading an existing file」から、展開した **すべてのファイル** を選んでアップロード →「Commit changes」。
4. Settings → Pages → Branch を `main` / `(root)` にして Save。
5. 数分後に表示される `https://（ユーザー名）.github.io/（リポジトリ名）/` をSafariで開きます。

### 方法B：Netlify Drop / Cloudflare Pages など
ZIPまたはフォルダをアップロードできる静的ホスティングでも構いません。

## 2. 初回セットアップ（Wi-Fi接続中）
1. 公開したURLをSafariで開く（ページが表示されたら一度再読み込みして、Service Workerを有効にする）。
2. 「モデル管理」→ 一覧のいちばん小さいモデルから「ダウンロードして読み込む」。
3. 完了後、「状態・ヘルプ」で各項目が ✅ か確認し、「保存データの保護を要求」を押す。
4. チャットで1往復会話できることを確認。

## 3. ホーム画面に追加
Safariの共有ボタン →「ホーム画面に追加」。以後はホーム画面のアイコンから起動します（保存データも消えにくくなります）。

## 4. オフライン動作の確認
1. Wi-Fiを切る（または機内モード）。
2. ホーム画面のアイコンから起動する。
3. 前回のモデルが自動で読み込まれ、チャットできれば成功です。
   自動で読み込まれない場合は「モデル管理」→「このモデルを使う」。

## 5. モデルを追加・切り替え・削除
- 追加：オンライン時に「モデル管理」→ 一覧から「ダウンロードして読み込む」。
- 切り替え：ダウンロード済み一覧の「このモデルを使う」。
- 削除：「削除」ボタン（保存容量が戻ります）。

## 6. 対応環境と制約
- 対応見込み：WebGPUが使えるSafari（iPadOS 26以降）。
- iPadのSafariはタブのメモリ上限が厳しく、モデルが大きいとページが強制終了することがあります。1B前後のモデルから試してください。強制終了した場合、次回起動時にその旨を表示します。
- WebGPUのバッファ上限により、大きいモデルは読み込めないことがあります。
- AIモデルの保存はWebLLMがブラウザのCache Storageに行います。Safariは容量不足などで削除することがあり、保証はありません。消えた場合は再ダウンロードしてください。
- ダウンロードの再開は「完了したファイルを再利用して続きから」までです（ファイル途中からのRange再開は行いません）。
- 初回読み込みに成功したモデルだけがオフラインで使える可能性があります（モデル用wasmも初回読み込み時に保存されるため）。
- 日本語性能は、Qwen系が比較的よいと思われますが未検証です。
- アプリ内の「ダウンロード目安」は必要GPUメモリからの概算です。実際の容量とは異なります。

## 7. 通信について
- 初回: アプリ配布元、`cdn.jsdelivr.net`（WebLLM本体）、モデル配布元（Hugging Face など）、wasm配布元（GitHub）にファイル取得のためアクセスします。
- チャットの内容は端末の外へ送信されません（会話履歴は端末のlocalStorageに保存）。

## 8. 困ったとき
- 画面が真っ白／WebLLMを読み込めない → オンラインでURLを開き直す。
- 「メモリ不足」「バッファ上限」 → 小さいモデルに変更、他のタブを閉じる。
- 「保存容量が足りない」 → 不要なモデルを削除、iPadの空き容量を増やす。
- オフラインで起動しない → 「状態・ヘルプ」で ✅ にならない項目を確認し、オンラインでもう一度モデルを読み込む。
- 更新を反映したい → ホーム画面のアプリを完全に終了して2回起動する。

## 9. 軽量化・クラッシュ対策（v3）
- 通常は必要GPUメモリ2GB以下のモデルだけ表示。重いモデルは「重いモデルも表示」をオンにしたときだけ表示（落ちやすい）。
- iPadのSafariが対応していない「q4f16」形式は自動で非表示（無駄なダウンロードを防ぐ）。
- 別のモデルに切り替えるときは、メモリを確実に空けるためページを自動で再読み込みしてから読み込みます。
- 会話の長さ・1回の返答の長さを、モデルの上限に合わせて自動で短くします。
- 画面の更新回数を減らし、返答中の負荷を下げています。
- 保存状況の確認は、1つずつ・時間制限つきで行います（一覧が空になる問題の対策）。
